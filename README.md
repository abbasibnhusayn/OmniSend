# OmniSend
Multi-channel messenger: SMS (GSM), WhatsApp, Messenger, Telegram. Text, photo, video, document (up to 500 MB each).

## Get the APK
1. Create a GitHub repo, upload all files in this folder (keep `.github/workflows/`), push to `main`.
2. Open the Actions tab > "Build APK" (runs automatically; or Run workflow).
3. When finished, download `OmniSend-apk` from the run's Artifacts, unzip, install `app-release.apk`.
